# Cycle Slip Simulation and Identification

This repository contains code and resources used for the "Geoinformatics Project" at Politecnico di Milano for the academic year 2025/2026. 

## Installation

Follow the steps below to set up the project:

1. Clone the repository:
    ```bash
    git clone https://github.com/AriannaBoisseau/geoinfo_project.git
    cd geoinfo_project
    ```

2. Create a virtual environment (optional but recommended):
    ```bash
    python3 -m venv venv
    source venv/bin/activate  # On Windows: venv\Scripts\activate
    ```

3. Install the required packages:
    ```bash
    pip install -r requirements.txt
    ```

## Requirements

The `requirements.txt` file contains all the dependencies needed for the project.
